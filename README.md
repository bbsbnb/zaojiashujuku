# AI 人材机价格助手 MVP

这是一个本地运行的个人造价数据库 MVP，用来管理历史项目 Excel 数据，并支持价格查询、新项目人材机补价、候选价确认和本地归档。

## 已实现的核心能力

- 本地 SQLite 资料库
- 历史项目 Excel 归档
- 价格库查询与筛选
- 建议价、参考区间、风险提示
- 新项目人材机表上传补价
- 每条补价项显示 3 个候选
- 人工 / 材料 / 机械 / 设备分类展示
- 手动确认候选价
- 项目库、价格库、补价任务库
- 最近查询、最近补价任务工作台

## 快速启动 Web 界面

推荐直接双击：

```text
启动本地Web界面.bat
```

启动后浏览器会打开：

```text
http://127.0.0.1:8765/
```

如果浏览器没有自动打开，请手动复制上面的地址访问。

## 命令行启动方式

也可以在当前目录运行：

```powershell
python -m cost_ai_mvp.web_app
```

## 默认目录

- 程序目录：当前文件所在目录
- 默认资料库：`AI造价数据库`
- 默认样本目录：`第一轮测试样本`
- 数据库文件：`AI造价数据库/database/cost_database.sqlite`
- 新项目补价输出：`AI造价数据库/new_projects`

## 推荐使用流程

1. 打开本地 Web 界面。
2. 点击“初始化/修复资料库”。
3. 点击“导入样本”，把历史项目 Excel 归档并解析入库。
4. 用“查询价格”查人工、材料、机械单价。
5. 上传新项目人材机表，生成建议价和参考区间。
6. 进入“补价任务”，按人工 / 材料 / 机械查看候选。
7. 对每条候选点击“确认”。
8. 下载补价结果 Excel。

## 常见问题

### 页面打不开

确认本地服务是否已经启动，并访问：

```text
http://127.0.0.1:8765/
```

如果端口被旧服务占用，可以关闭旧的命令行窗口后重新双击启动脚本。

### 查询或补价没有结果

通常是资料库还没有导入足够历史价格。先导入样本或导入真实项目 Excel。

### Excel 原文件会被改动吗？

不会。系统会复制一份到资料库中归档，原始文件不被修改。

### 没有 AI Key 能用吗？

能用。当前 MVP 的建议价和区间主要由本地历史数据匹配计算。OpenAI-compatible / DeepSeek 接入预留为后续增强。

## 当前定位

这是个人本地 MVP，不是多人协同系统。优先目标是：

- 把散落 Excel 变成可查询资料库；
- 让历史价格可复用；
- 让新项目补价有建议、有区间、有风险提示、有来源依据。
